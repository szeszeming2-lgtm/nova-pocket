# Nova Pocket

One offline app with 18 small apps inside: Calendar, Notes, Reminders, Passwords (encrypted vault), Map (world map + GPS), Weather (saved for offline), Photos, Music (your songs, built-in tunes, piano, beat maker), Voice Memos, Studio (draw, edit photos, filters), CFOP Learner (Rubik's cube lessons in plain words), Flashcards, Learn (math, periodic table, solar system, world quiz, word quiz), Dictionary (87,000 words), Chess and Games.

Everything you make is stored only on your own device. Open the page once with internet, then add it to your Home Screen (iPhone: Share → Add to Home Screen). After that it works with no internet. Weather is the only part that uses the internet, and only when you refresh it.
